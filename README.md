# FriendZone – Schedule-Based Friend Finder

**Live Demo:** [https://friendzone-frontend.vercel.app](...)

## What It Does
Helps users discover friends with overlapping availability by syncing Google Calendar data and matching schedules via a schedule-matching algorithm.

## Tech Stack
- **Frontend:** React, Vite
- **Backend:** Express.js, Node.js
- **Database:** Firebase (Auth + Firestore)
- **APIs:** Google Calendar API, Google Sign-In

## Features Implemented
- [x] Google OAuth Sign-In
- [x] User profile creation
- [x] Google Calendar sync
- [x] Schedule overlap matching algorithm
- [ ] Real-time notifications (future)
